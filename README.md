# What Type of Trader Are You?

An interactive educational resource developed by **Candle Iron Core Academy** as part of its trading education materials.

This assessment is designed to help students identify characteristics of their trading profile based on their preferences, decision-making, and approach to the markets.

## Candle Iron Core Academy

Professional trading education built on **Objectivity, Probability & Simplicity**.
